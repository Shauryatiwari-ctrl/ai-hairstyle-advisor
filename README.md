# 🌟 AI Hairstyle & Color Advisor

An intelligent web application that provides personalized hairstyle and hair color recommendations using Claude AI's advanced vision capabilities.

![AI Hairstyle Advisor](https://img.shields.io/badge/AI-Powered-purple)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- 📸 **Photo Upload** - Upload clear front-facing photos for analysis
- 🤖 **AI-Powered Analysis** - Uses Claude Sonnet 4 to analyze facial features
- 💇 **Personalized Recommendations** - Get 3 hairstyle suggestions tailored to your face
- 🎨 **Color Suggestions** - Receive 3 hair color recommendations that complement your skin tone
- 🎯 **Face Shape Detection** - Automatic detection of face shape and skin tone
- ⚙️ **Customizable Preferences** - Optional inputs for face shape, skin tone, and desired hair length
- 💡 **Styling Tips** - Practical advice on maintaining your new look

## 🚀 Demo

Simply open `index.html` in your web browser to start using the application!

## 📋 Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for CDN resources and API calls)
- Anthropic API access (automatically handled in claude.ai environment)

## 🛠️ Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/ai-hairstyle-advisor.git
cd ai-hairstyle-advisor
```

2. Open `index.html` in your web browser:
```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

That's it! No build process or dependencies to install.

## 📖 How to Use

1. **Upload Photo**: Click the upload area and select a clear, front-facing photo
2. **Set Preferences** (Optional): Choose your face shape, skin tone, or desired hair length
3. **Get Recommendations**: Click "Get Recommendations" button
4. **Review Results**: View AI-analyzed face features and personalized suggestions

## 🎯 Best Practices for Photos

- Use well-lit, clear photos
- Face the camera directly
- Ensure your full face is visible
- Avoid heavy filters or editing
- Remove accessories that obscure your face (hats, sunglasses)

## 🏗️ Technology Stack

- **Frontend**: React 18 (via CDN)
- **Styling**: Tailwind CSS
- **AI**: Claude Sonnet 4 (Anthropic API)
- **Build**: No build process - pure HTML/JS

## 🔒 Privacy & Security

- Images are processed client-side before being sent to the API
- No images are stored permanently
- API calls are made directly from your browser
- Works within claude.ai's secure environment
